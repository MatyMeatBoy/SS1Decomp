# Credits

## Original Shining Soul decompilation

**emmkay440 (emmkay)** created the original Shining Soul decompilation and
established its matching C, assembly, build system, research and documentation.
This project continues that work with permission, preserving the original Git
history and attribution.

- Upstream: https://github.com/emmkay440/SS1Decomp
- Permission and collaboration: https://github.com/MatyMeatBoy/SS2Decomp/issues/79#issuecomment-6822092880

His original work and subsequent contributions will remain credited here and in
projects derived from this work. The original contribution history remains the
authoritative record of individual authorship.

## Continuation and shared research

**MatyMeatBoy** maintains this fork, progress reporting and the SS2-to-SS1
comparison work. The completed matching code and engineering findings in
[SS2Decomp](https://github.com/MatyMeatBoy/SS2Decomp) provide reference material;
each SS1 adaptation must independently match the SS1 USA ROM.

The original README documents the external compiler, disassembler and Nintendo
library research sources. Their existing notices and credits are preserved.

Shining Soul and its original game content belong to their respective owners.
This repository does not distribute the game ROM or extracted game assets.
